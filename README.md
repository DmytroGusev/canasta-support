# Canasta Salon support URL bridge

The application website, support, privacy policy, terms and cookie notice are published at https://guruofcards.com/apps/canasta/.

This repository retains the original GitHub Pages URLs used by existing app builds and redirects them to the corresponding Guru of Cards pages. It does not change DNS or add a CNAME for the main domain.

The website source and four-language media kit are maintained in DmytroGusev/masti-card-encyclopedia under src/apps/canasta and scripts/app-pages.mjs.
